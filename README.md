# Sandbox (2021 to 2024)

Small programs from my first years of coding: practice, experiments and one-afternoon tools. Each folder is separate and kept as written, so some use libraries or APIs that have since changed.

The bigger projects from these years have their own repositories (HonestClock, Graphy, ColorWheel, MailManager, Computer_Vision, MovieRating and others).

See the table below for what each folder is. Run any Python one with `python <file>.py` after installing what it imports.

| Folder | Year | What it is |
|---|---|---|
| `python-projects-2021/` | 2021 | First Python practice scripts |
| `python-projects-2022/` | 2022 | Pygame games (Helicopter Battle and others) and practice programs |
| `cpp-practice/` | 2022 | C++ tutorials worked through, one file per lesson |
| `randgen/`, `random-team/` | 2022, 2023 | Random number and random team generators |
| `freelancer-auth/` | 2022 | Flask sign-up and login with bcrypt and a colour-wheel password page |
| `pybot/` | 2022 | Selenium browser automation: finding elements and clicking by position |
| `enactus-page/` | 2022 | Static page for Enactus ARSD |
| `autochat/` | 2023 | Sends messages from a CSV with Selenium and keyboard automation |
| `canteen-billing/` | 2023 | Command-line restaurant billing with MySQL: menu, orders, bills, daily to yearly reports |
| `mailmanager-flask/` | 2023 | Web front end for the MailManager app |
| `student-marks/` | 2023 | Student marks program |
| `ai-virtual-mouse/` | 2023 | Control the mouse with hand gestures through the webcam (OpenCV, MediaPipe) |
| `openai-flask/`, `chatbot-page/`, `gpt-chat-ui/` | 2023, 2024 | Chat interfaces on the OpenAI API |
| `ai-saas-landing/` | 2023 | Landing page and small web tools: CSS extractor, code viewer, text to speech, subtitles |
| `fishery/` | 2023 | Page and email template |
| `eunoia/` | 2023 | Music generation web page |
| `admin-panel/` | 2023 | Electron desktop admin app |
| `admin-py/` | 2023 | Flask admin dashboard on Firebase |
| `fic-sponsor/` | 2023 | Sends sponsorship emails for the Finance and Investment Cell over SMTP |
| `pymusic/` | 2023 | Plays generated notes and melodies with Pygame and NumPy |
| `email-ticket/` | 2023 | Generates event tickets from a CSV and emails them |
| `screen-record/` | 2023 | Screen recorder in Python |
| `python-ai-experiments/` | 2023 | Genetic algorithm, prime finder and sentiment analysis |
| `android-cam/` | 2023 | Captures frames from a phone camera and stitches them with OpenCV |
| `unicode-gen/` | 2024 | Fancy Unicode text generator |
| `speech-ai/` | 2024 | Speech recognition from the microphone |
| `parallax/` | 2024 | Parallax scrolling page |
| `linkedin-font/` | 2024 | Flask tool that reads LinkedIn content and drafts text with Gemini |

| `videogen/` | 2024 to 2025 | Turns images into short videos with the Stability AI API |
| `frontend-2024/`, `brand-test/` | 2024 | Front-end layout experiments |

API keys and passwords that were written into some of these scripts have been replaced with `REDACTED`. Put your own key in an environment variable to run them.
